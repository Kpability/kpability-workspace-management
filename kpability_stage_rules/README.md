Configure what people see, can edit, or must fill in on the standard Odoo CRM opportunity form. The add-on depends only on `crm` and does not require Studio.

1. As a CRM administrator, open **CRM → Configuration → Stage Rules**.
2. Select one or more **Stages** and **Opportunity Fields**. If a field is missing, type in the field dropdown and choose **Create and edit…** to register a field already on the opportunity form. This does not add a field to CRM.
3. Leave **User Groups** blank for everyone in the opportunity's company, or select the groups that should see the rule. Choose **Visibility**, **Editing**, or **Requirement**. Each conditional option has its own condition builder with choices for the selected field type.
4. Turn on **Active**, save the rule, and reopen an opportunity to try it.
